# Data Model: URL Ingestion and Embedding Pipeline

## Entity: DocumentChunk
**Description**: Represents a segment of text extracted from documentation with associated metadata and vector embedding

**Fields**:
- `chunk_id` (string): Unique identifier for the chunk
- `content` (string): The actual text content of the chunk
- `embedding` (list[float]): Vector embedding generated by Cohere model
- `url` (string): Original URL where this content was found
- `module` (string): Module/section name from the documentation structure
- `section` (string): Specific section within the module
- `source_path` (string): Path within the documentation site
- `token_count` (int): Number of tokens in the chunk
- `created_at` (datetime): Timestamp when chunk was created

**Validation Rules**:
- `content` must not be empty
- `embedding` must have the correct dimensions for the Cohere model used
- `url` must be a valid URL
- `token_count` must be within the range specified in requirements (related to chunk size)

## Entity: CrawledPage
**Description**: Represents an individual page or section from the Docusaurus documentation site

**Fields**:
- `page_id` (string): Unique identifier for the page
- `url` (string): URL of the page
- `title` (string): Title of the page from HTML
- `content` (string): Raw HTML or text content extracted from the page
- `module` (string): Module/section this page belongs to
- `section` (string): Specific section name
- `links` (list[string]): URLs of links found on this page
- `status_code` (int): HTTP status code when fetching the page
- `fetched_at` (datetime): Timestamp when page was fetched

**Validation Rules**:
- `url` must be a valid URL
- `status_code` must indicate successful fetch (200) or be properly handled for errors
- `content` must not be empty for successfully fetched pages

## Entity: EmbeddingRecord
**Description**: Represents a vector embedding record stored in Qdrant with associated metadata

**Fields**:
- `record_id` (string): Unique identifier used by Qdrant
- `vector` (list[float]): The embedding vector (1024 dimensions for Cohere)
- `payload` (dict): Metadata stored with the vector containing:
  - `url` (string): Original source URL
  - `module` (string): Documentation module
  - `section` (string): Documentation section
  - `content` (string): Original text content (potentially truncated)
  - `source_path` (string): Path within documentation site
- `collection_name` (string): Name of the Qdrant collection

**Validation Rules**:
- `vector` must have correct dimensions (1024 for Cohere embed-multilingual-v3.0)
- `payload` must contain required metadata fields
- `record_id` must be unique within the collection

## Entity: CrawlConfiguration
**Description**: Configuration parameters for the crawling process

**Fields**:
- `base_url` (string): Root URL of the Docusaurus documentation site
- `include_patterns` (list[string]): URL patterns to include in crawling
- `exclude_patterns` (list[string]): URL patterns to exclude from crawling
- `max_depth` (int): Maximum depth to crawl from the base URL
- `delay_between_requests` (float): Delay in seconds between requests to be respectful
- `timeout` (int): Request timeout in seconds
- `user_agent` (string): User agent string to use for requests

**Validation Rules**:
- `base_url` must be a valid URL
- `max_depth` must be a positive integer
- `delay_between_requests` must be non-negative
- `timeout` must be a positive integer

## Relationships

```
CrawledPage 1 -> * DocumentChunk
DocumentChunk 1 -> 1 EmbeddingRecord
```

A single `CrawledPage` can be split into multiple `DocumentChunk` entities, and each `DocumentChunk` corresponds to one `EmbeddingRecord` in Qdrant.

## State Transitions

### DocumentChunk
- `created` → `embedded` → `stored`
  - When a chunk is first created from a page
  - When the embedding is generated for the chunk
  - When the chunk is successfully stored in Qdrant

### CrawledPage
- `fetched` → `processed` → `chunks_created`
  - When the page content is successfully fetched
  - When the page content is parsed and processed
  - When document chunks are created from the page content
